# Profile photos

Drop real photos here (jpg, jpeg, png or webp). Shift uses them before generating an avatar.

Expected names: `ilya.jpg`, `rahul.jpg`, `jordan.jpg`, `testimonial-1.jpg`,
`testimonial-2.jpg`, `testimonial-3.jpg`. Any other file named after a person id
(for example `maya.jpg`, `noah.jpg`) is used for that seeded worker.

`npm run dev` and `npm run build` refresh `src/data/profile-photos.json` automatically.
